# Dataset Schema: Bank Loan Evaluation Research Dataset (3,000 Records)

## 1. Overview & Purpose
This dataset is designed for academic research on **"An Explainable Policy-Aware Agentic AI Decision Support System for Bank Loan Evaluation Using Machine Learning Predictions"**. 

The primary research dataset (`loan_evaluation_dataset_3000.csv`) combines:
- **500 empirical survey responses** collected via Google Form questionnaires (`data/raw/google_form_responses_500.csv`), and
- **2,500 synthetic tabular records** generated using the Conditional Tabular GAN (`CTGAN`) synthesizer from the official **Synthetic Data Vault (SDV)** library (`data/synthetic/sdv_generated_2500.csv`).

---

## 2. Dataset Metadata & Lineage
- **Primary Benchmark Filename:** `loan_evaluation_dataset_3000.csv`
- **Total Records:** 3,000 records
  - *Rows 0–499:* 500 original Google Form survey responses
  - *Rows 500–2999:* 2,500 SDV CTGAN synthetic records
- **Total Features:** 17 (16 Predictors + 1 Target Variable)
- **Target Variable:** `Loan Application Result`
- **Target Classes:**
  - `Approved`: 1,045 records (34.83%)
  - `Rejected`: 1,955 records (65.17%)
- **Missing Values:** 0 across all fields (100% complete)
- **Duplicate Rows:** 0 (100% unique profiles, 0 overlap with seed responses)
- **PII Compliance:** 100% anonymized records with no personally identifiable information.

### Legacy Dataset Reference
- **Legacy Filename:** `loan_evaluation_synthetic_2000_up_to_100m.csv`
- **Status:** **LEGACY / PREVIOUS DATASET (Reference Only)**
- **Purpose:** Retained for benchmark archiving and historical model development comparisons.
