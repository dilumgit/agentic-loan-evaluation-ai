# Feature Mapping & Interpretation Guide for Explainable AI (XAI)

## 1. Context & Purpose
- **Research Title:** *“An Explainable Policy-Aware Agentic AI Decision Support System for Bank Loan Evaluation Using Machine Learning Predictions”*
- **Objective:** Establish an unambiguous, bidirectional mapping between the **16 empirical borrower features**, their **55 numerical representations** generated by the preprocessing pipeline, and the **human-understandable explanations** produced by SHAP and LIME for bank officers.

---

## 2. Preprocessing Architecture: 16 Raw Features to 55 Model Inputs

The authoritative preprocessor pipeline utilizes a `ColumnTransformer` comprising:
1. **Ordinal Encoding Pipeline (6 features):** Mapped into monotonically ascending integers ($0, 1, 2, \dots$) representing natural banking risk hierarchies.
2. **One-Hot Nominal Encoding Pipeline (10 features):** Expanded into 49 binary indicator dummy variables ($0$ or $1$).

$$\text{Total Transformed Features} = 6 \text{ (Ordinal)} + 49 \text{ (One-Hot)} = \mathbf{55 \text{ Features}}$$

## 4. Translating XAI Attributions into Banking Terms

When SHAP or LIME assigns a positive or negative weight to a model feature, bank officers can interpret it using the following framework:

| Model Feature Representation | Attribution Direction | Translation for Bank Credit Officers |
|---|---|---|
| `Required Documents Submitted_Yes, all` = 1 | **Positive (+)** | Complete regulatory documentation submitted; increases credit verification confidence. |
| `Required Documents Submitted_No, some missing` = 1 | **Negative (-)** | Critical required documentation is incomplete; creates substantial non-compliance risk. |
| `Existing Loan Status_No` = 1 | **Positive (+)** | Applicant has no existing debt obligations, indicating unencumbered cash flow. |
| `Requested Loan Amount` = High Tier (4–5) | **Negative (-)** | Large principal quantum increases credit risk exposure relative to applicant profile. |
| `Monthly Income` = High Tier (4–5) | **Positive (+)** | Strong monthly debt-servicing capacity reduces probability of default. |
| `Collateral Availability_Yes` = 1 | **Positive (+)** | Secured loan application reduces loss-given-default (LGD). |
| `Collateral Availability_No` = 1 | **Negative (-)** | Unsecured exposure increases institutional credit risk. |
| `Loan Purpose_Debt consolidation` = 1 | **Negative (-)** | Restructuring existing liabilities signals potential historical cash-flow stress. |
